# IT Helpdesk Ticket Registration System

## Purpose

This Python application allows students to register technical issues.

The system collects:

- Student name
- Student ID
- Technical issue
- Location
- Priority level

The system assigns a technician based on the priority level.

## Technician Assignment

- High Priority: Ahmad
- Medium Priority: Siti
- Low Priority: Ali
