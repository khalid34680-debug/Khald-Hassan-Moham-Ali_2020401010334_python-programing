# Food Delivery System

## Purpose

This application collects customer food-order information and generates a receipt.

## Tech Stack

- Python
- GitHub

## How to Use

1. Download or clone the project.
2. Open the week_8 folder.
3. Run the following command:

python main.py

4. Enter the customer information.
5. The receipt will be displayed.
